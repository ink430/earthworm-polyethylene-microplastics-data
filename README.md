# Earthworm polyethylene microplastics data

This repository contains supporting data for the study:

**Particle size and concentration govern polyethylene microplastic effects on earthworm fitness and gut microbial functional potential**

## Data files

### Microplastics_Data_English.xlsx
Experimental data associated with polyethylene microplastic exposure treatments in earthworms.

### Statistical_Values_with_Cocoon_English.xlsx
Statistical data for earthworm fitness endpoints, including mortality, biomass, and reproductive output.

## Experimental design

Earthworms were exposed to polyethylene microplastics with four particle sizes and three concentrations.

- Particle sizes: 15, 45, 100, and 200 μm
- Concentrations: 0.5%, 2%, and 5%
- Control group: no polyethylene microplastic exposure

## Microbial sequencing

Earthworm gut microbial communities were characterized by 16S rRNA gene amplicon sequencing targeting the V3–V4 region.

The raw sequencing data have been deposited in the NCBI Sequence Read Archive (SRA) under BioProject accession number [PRJNA1530731](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1530731).
